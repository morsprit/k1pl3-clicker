# K1PL3 Clicker v2

Мемный кликер на HTML/CSS/JavaScript без сборки и сторонних библиотек.

## Локальный запуск
Открой `index.html` или запусти `npx serve .`.

## Деплой на Vercel
1. Загрузи содержимое репозитория на GitHub.
2. Импортируй репозиторий на https://vercel.com/new.
3. Framework Preset: `Other`; Build Command не нужен, Output Directory — `.` (корень проекта).
4. Нажми Deploy.

## Функции
- Клики, критические клики и плавающие числа
- Апгрейды и пассивный доход
- Звуковые эффекты через Web Audio API (включаются после первого взаимодействия)
- Достижения и ранги
- Выбор цветовой темы и масштаба портрета
- Случайные временные события
- Локальный рекорд и автосохранение через localStorage

Изображение хранится в `public/k1pl3.jpeg`. Прогресс не синхронизируется между устройствами; рейтинг локальный.
